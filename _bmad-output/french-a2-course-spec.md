# Курс «Французский A2» в Memora — спецификация

## Источник
Программа и темы — учебник **Édito A2** (Didier FLE, 2e éd. 2022), 12 юнитов.
Структура извлечена из оглавления и индекса грамматики PDF. **Весь контент написан с нуля
по программе** (правила, примеры, слова, задания) — без копирования текста и аудио учебника
(авторские права Didier/Hatier). Аудио/видео учебника остаются для личного прослушивания
пользователя на его диске и не публикуются в сервисе.

## Что реализовано
1. **Данные курса** `memora-web/src/lib/courses/frenchA2.ts`
   - 12 юнитов: тема (fr/ru), коммуникативные цели, правила грамматики с примерами, банк лексики (72 слова).
   - Диагностический тест: 45 заданий по всем юнитам и 4 навыкам (grammar/vocab/listening/speaking), каждое с правилом-объяснением.

2. **Страница курса** `…/dashboard/student/courses/french-a2/page.tsx` — 5 вкладок:
   - **Диагностика** — тест на выявление пробелов; итог по навыкам и по 12 юнитам, рекомендации, разбор ошибок с правилами.
   - **Грамматика** — раскрывающийся справочник правил по юнитам с озвучиванием примеров.
   - **Лексика** — флешкарты (переворот, фильтр по юнитам, перемешивание) с TTS (Inworld/браузер).
   - **Аудирование** — задания «послушай → ответь».
   - **Говорение** — запись голоса и оценка произношения (Web Speech / серверный whisper).

3. **Сид-миграция** `memora-api/migrations/20260601010000_seed_french_a2_course.sql`
   - Набор A2 (UUID `a2a2a2a2-…0001`) + 72 карточки лексики (UUID `a2c0a2c0-…`), схема с TTS fr (Alain).
   - Идемпотентно; применяется автоматически через `sqlx::migrate!()`. Даёт FSRS-повторения и Q-Chat для лексики A2.

4. **Дашборд** — две карточки курсов (A1 синяя, A2 зелёная).

## Переиспользование существующего
- ИИ-проверка текстовых ответов → `/api/ai/learn/grade` (Ollama).
- TTS → `/api/audio/{cardUuid}/term_audio` (Inworld), fallback — браузерный синтез.
- Произношение → серверный whisper (feature `stt`) или Web Speech.

## Креативные идеи — РЕАЛИЗОВАНО (все 8)
Файлы: `memora-web/src/lib/courses/frenchA2Extra.ts` + вкладки на странице курса A2.
1. ✅ **Адаптивный путь** — вкладка «Мой план»: после диагностики слабые юниты сохраняются в localStorage, план собирается автоматически.
2. ✅ **Аудио-диктанты** — вкладка «Диктанты»: TTS читает фразу → ученик пишет → similarity + ИИ-сверка (Ollama).
3. ✅ **Генеративный тренажёр спряжений** — вкладка «Спряжения»: бесконечные примеры (présent/passé composé/imparfait/futur/subjonctif), серия-стрик, ИИ для спорных форм.
4. ✅ **Ролевые диалоги** — вкладка «Диалоги»: 3 сценария (ресторан/врач/вокзал), бот ведёт реплики, ученик произносит свои (Web Speech/whisper).
5. ✅ **«Ошибка дня»** — баннер на странице (детерминирован по дате) + scheduled task `french-a2-mistake-of-the-day` (ежедневно 9:00).
6. ✅ **Геймификация** — XP, уровни/титулы, стрик по дням, бейджи (диагностика, DELF), панель сверху (localStorage).
7. ✅ **Карточки с картинками** — эмодзи-образы к каждому слову в тренажёре лексики (визуальная память).
8. ✅ **Épreuve blanche DELF A2** — вкладка «Экзамен»: 20 смешанных заданий с таймером, порог 50%, сертификат-бейдж.

Интервальные повторения (FSRS) подключаются автоматически через сид-набор A2 (лексика как обычный set Memora).

## Креативные идеи (исходный бэклог)
1. **Адаптивный путь**: после диагностики автоматически собирать персональный набор заданий из слабых юнитов (можно генерировать через Ollama `/api/ai/learn/generate`).
2. **Аудио-диктанты из учебника**: проигрывать аудио Édito (личное, по ссылке у пользователя) → ученик пишет → ИИ-сверка. Аудиофайлы не хостим, только локальный путь/ссылка.
3. **Спряжение-тренажёр**: отдельный дрилл passé composé / imparfait / futur / subjonctif с генерацией бесконечных примеров через Ollama и мгновенной проверкой.
4. **Ролевые диалоги (speaking)**: сценарии из тем юнитов (ресторан, врач, путешествие) — ученик говорит реплики, whisper оценивает; Q-Chat играет собеседника.
5. **«Ошибка дня»**: ежедневная карточка с типичной ошибкой A2 (через scheduled task + push).
6. **Геймификация**: стрик-счётчик, бейджи за юниты, мини-босс «épreuve blanche DELF A2» в конце.
7. **Карточки с картинками**: image-поле для лексики (визуальная память) — поле image уже поддержано схемой.
8. **Интервальное аудирование**: связать listening-задания с FSRS, чтобы трудные возвращались чаще.

## Расширение (по материалам Édito/Odyssée/Nouvelle Génération/FLE au top A2)
- **Банк вопросов** `frenchA2Bank.ts`: +160 заданий → полный пул **205** (диагностика 45 + банк 160). Покрывает все грам.точки A2, фонетику/орфографию (омофоны, акценты, liaison, élision), числа/даты, предлоги времени (depuis/en/dans), формы вопросов.
- **Диагностика** теперь идёт по всему пулу (205), с разбором по 12 юнитам и 4 навыкам, «Перемешать» для прохождения частями.
- **Фразы** `frenchA2Phrases.ts`: 40 ходовых выражений по ситуациям + вкладка «Фразы» (карточки с TTS/FSRS + тест RU→FR). Отдельная сид-миграция набора фраз.
- **Аудирование до автоматизма**: вкладка «Диктанты» объединяет короткие и **12 сложных** многофразовых диктантов (уровни 1–3), режим «по словам» с паузами.
- **Диалоги**: +5 сценариев (магазин, отель, телефон, собеседование, булочная) → всего 8.
- **Спряжения**: таблица глаголов расширена (être, avoir, aller, faire, venir, prendre, pouvoir, vouloir, devoir, savoir, finir, partir, voir) — 13 глаголов × 5 времён.
- **Экзамен DELF** усложнён: **100** вопросов из полного пула, таймер, порог **60%**, бейдж + 50 XP.
- Озвучивание везде — только Inworld (`/api/tts` + кэш).
