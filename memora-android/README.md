# Memora для Onyx Boox

Приложение-оболочка: Memora в собственном окне, без браузера и его расширений.

## Зачем оно

В браузере читалке мешают расширения. Плагин переводчика перехватывает
выделение текста, и выбор фразы перестаёт работать — страница о таком даже не
узнаёт. Здесь свой WebView, расширений в нём нет вовсе.

Остальное — обвязка под экран из электронных чернил:

* быстрый режим обновления экрана через SDK Onyx (по отражению: нет SDK — нет и
  беды, приложение работает как обычно);
* никаких анимаций и оконных переходов — на чернилах каждая из них платится
  полной перерисовкой;
* экономное оформление Memora включается само при запуске;
* кнопки громкости и выносная «листалка» по Bluetooth перелистывают страницу;
* микрофон и выбор файла проброшены наружу — иначе не работали бы проверка
  произношения и загрузка книг.

## Как получить APK

Сборка идёт на GitHub при каждом изменении папки `memora-android`. Готовый файл
лежит во вкладке Actions → последний запуск → раздел Artifacts →
`memora-boox-apk`.

На устройстве нужно разрешить установку из неизвестных источников.

## Как собрать у себя

Открыть папку `memora-android` в Android Studio и запустить сборку. Обёртки
`gradlew` в проекте нет: Android Studio подставит свою.
