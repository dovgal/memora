# Пилот `language-en`: чек-лист ручной проверки

> Цель: убедиться, что мультиязычная архитектура (Subject Packs) работает на живом
> сервисе, и французский не деградировал. Прогоняется на проде (Railway) после деплоя.
> Паки de/es включены той же механикой — прогон по этому же списку, если понадобятся.

## A. Английский курс — полный цикл

1. **Создание.** Курсы → «Создать курс» → в редакторе: язык «Английский», уровень A1,
   название «English A1 (pilot)». Сохранить.
2. **Генерация юнита.** Добавить юнит → ИИ-генерация, тема «Greetings and introductions».
   Ожидание: лексика EN↔RU, упражнения на английском, объяснения по-русски,
   промпт-персона — «методист по английскому языку» (проверить качество контента).
3. **Озвучка.** В юните нажать озвучку фразы. Ожидание: английский голос (Clive),
   не французский Alain. Проверить и TTSInput в карточках.
4. **Коуч.** Пройти юнит в коуч-режиме: авто-оценка, FSRS-планирование, лестница
   подсказок. Ожидание: работает без изменений (ядро предметно-нейтрально).
5. **Вариант на повторе.** Разметить одно упражнение правилом (rule.skill/point)
   → оценить «Снова» → на повторе должен прийти НОВЫЙ вариант на английском.
6. **Разговор/Чтение/Shadowing.** Все три режима: реплики и истории на английском,
   переводы на русский, распознавание речи en-US, голос Clive.
7. **Словарь.** В чтении кликнуть слово → «В словарь» → набор «Словарь · English A1 (pilot)»
   появился в наборах с карточкой.

## B. Французский — отсутствие регрессий

1. Édito A1: юнит открывается, упражнения рендерятся, озвучка — голос Alain
   **из кэша** (мгновенно, без регенерации — ключ кэша не менялся).
2. Коуч Édito A1: сессия собирается (план сервера), повторения идут, вариант
   error-hunt на повторе — французский, промпт-персона Voltaire не изменилась.
3. Пользовательский FR-курс: генерация юнита — контент французский (промпт 1:1).
4. A2-тренажёр: «Мой план», генерация заданий по слабым темам — работает.

## C. Что смотреть в логах Railway

- `variant-pregen: generated N variant(s)` — воркер жив и наполняет запас.
- Ошибки `LLM provider error` — если появились, проверить `OLLAMA_API_KEY`/квоту.
- `Inworld API Error` на EN-фразах — проверить, что голос `Clive` доступен на аккаунте.

## Известные ограничения пилота

- Уровень объяснений — русский (для семьи это норма; язык объяснений станет
  настройкой в фазе 3, см. план §3.1).
- `subject` в UI курса пока не выбирается (всегда 'language') — селектор появится
  вместе со школьными предметами (слайс 16).
